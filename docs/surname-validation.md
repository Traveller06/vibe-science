## 实现取舍及影响

1. 私有仓库无法经本地CLI克隆，使用授权GitHub接口读取独立源码副本。远程提交以原树为基础，只更新明确文件；本地副本不含完整仓库历史。
2. 初始测试误预计26句，按批准原文纠正为22句，且测试逐句全量相等，不遗漏叙述。
3. 使用按帧取字幕的自定义组件满足批准版式。音频尚不存在，后续需按实际朗读重新校准时码。
4. 当前环境无法访问用户Windows播放进程，采用全3600帧运行渲染与1080p静帧检查。没有把用户机器实时播放标为通过。
5. 预览按规格使用系统中文字体回退。本环境Noto Sans CJK SC，Windows Microsoft YaHei；正式导出需固定授权字体，以消除字形度量差异。

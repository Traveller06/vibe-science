# 阶段二：配音与导出

2026-10-05，用户认可视觉版并要求继续，沿用连续执行和GitHub备份授权。

目标：保留六幕和22句批准文案，生成平稳普通话旁白，按实际测得音频校准字幕，交付可播放的1080p H.264/AAC MP4与SRT。默认普通话男声，不仿冒任何真人。

1. 先验证音源可用，生成逐句音频并记录引擎、声音、参数及实际时长；不把失败请求当成已生成。
2. 将逐句语音放入对应六幕，在120秒框架内优先自然语速；若实际朗读不适合原时长，则调整场景预算并记录，不截断句子。字幕依实际声段起止。
3. 固定授权中文字体，保留4.0.530依赖；旁白配轻量原创氛围底音（不使用未授权录音），音量低于语音。
4. 验证字幕完整且在片内、每句音频可解码、音轨有信号、分辨率/时长/帧率正确，检查首尾与场景交界。
5. 音源不可用时，完成可做的字幕/导出/恢复工作，明确阻塞；不伪称完成有声成片。
6. 源码、音频、字幕、字体授权与进度保存GitHub；大型交付视频单独持久保存，不往Git仓库堆叠大型导出。
